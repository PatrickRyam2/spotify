# 🎵 Spotify Clone

Projeto desenvolvido durante meus estudos de desenvolvimento web, inspirado na interface do Spotify.

## 📌 Sobre o projeto

O objetivo deste projeto foi praticar a criação de uma página web utilizando HTML e CSS, trabalhando com estruturação de conteúdo, estilização e organização de elementos.

O projeto também foi desenvolvido com foco em responsividade, buscando adaptar a interface para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## ✨ Conceitos praticados

- Estruturação de páginas com HTML
- Estilização com CSS
- Flexbox
- Responsividade
- Organização de layouts
- Utilização de imagens e elementos visuais

## 📱 Responsividade

O projeto foi desenvolvido buscando oferecer uma experiência adequada em diferentes tamanhos de tela.

## 🎯 Objetivo

Este projeto faz parte do meu processo de aprendizado em Desenvolvimento Front-End e representa uma etapa da minha evolução com HTML e CSS.
